# AMN Homepage — Direction B
Brief: docs/Creative-Brief.md. PRD: docs/PRD.md.

## Scope
- Work ONLY inside /direction-b/. Never edit /baseline/ or the original bundled prototype.
- Never commit the .claude/ folder.

## Project rules (brief §3, §5)
- This round adds look and feel only. Do NOT change copy, section order, navigation items, or interactions.
- Alert strip: collapsed by default, max 3 alerts, visually quiet.
- Letter steps: always visible, no accordion or hover reveal.
- Nav collapses to hamburger at 1140px and below.
- Must work 320–2560px with no horizontal scroll; design for 1440 and 375.
- WCAG 2.1 AA: text ≥ 4.5:1, large text/UI ≥ 3:1, visible focus on every control, touch targets ≥ 44×44, color never the only signal.
- One primary and one secondary button style only.
- All colors, fonts, spacing, radius, and shadows come from /direction-b/styles/tokens.css. Never hard-code values in component styles.
- Verify changes in the browser before saying they're done.

## Direction B — State of Arizona Agency Platform
- Lexend for headlines, Archivo for body (Arial fallback).
- Primary: Open Skies Turquoise. Primary CTA or highlights: Sunrise Copper. Support: Desert Sage. Text: navy or near-black.
- Use text-safe darkened shades wherever turquoise or copper holds white text.
- Each homepage section gets a visually distinct background (call-center wayfinding).
- AZ MVD Now stays visible as the agency sub-brand alongside the State identity.
- Car photo is optional (secondary placement or omitted).
